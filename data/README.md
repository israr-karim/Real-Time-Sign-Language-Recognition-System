# Local data

Dataset videos, customized annotations, cached features, and checkpoints are excluded from Git. Configure their locations using the environment variables described in `docs/reproduction.md`.

The historical notebooks expect converted PHOENIX-2014T MP4 files and customized Excel annotation sheets. Those local preparation artifacts are not bundled here.

Obtain upstream data through the [official RWTH-PHOENIX-Weather 2014T page](https://www-i6.informatik.rwth-aachen.de/~koller/RWTH-PHOENIX-2014-T/). Follow the [dataset guide](../docs/dataset.md) for provenance, citation, local preparation requirements, and the current status of usage-term verification.
